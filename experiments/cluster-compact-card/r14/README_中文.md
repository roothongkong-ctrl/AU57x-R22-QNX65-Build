# R14 / 真正 H.264 解码到70%卡片合成器（源码实验）

## 本轮新增
- card112_ffmpeg_decoder.h：复用 MIB v1.2.14 的 FFmpeg H.264 解码体系，接收已经解密、转换成 Annex-B 的独立112 H.264码流，输出连续的YUV420/I420帧。
- 将解码出来的原卡片112帧提交给R12会话同步器；R12使用111无卡片完整地图作为背景，将卡片按70%贴回；原来地图的其他像素不会变。
- 线程安全边界：每个112解码器独立持有FFmpeg上下文，不与111解码器或其他112会话共享；R12内部锁保护帧配对。
- 对任何不符合800x298/YUV420P、旧会话、视频解码失败的结果默认拒绝输出合成，保持原111画面不动。

## GitHub真实编译与测试
使用FFmpeg编码一段H.264 800x298的白卡片视频，然后由实际libavcodec解码到I420，执行R12合成，逐字节比较三个YUV平面上所有卡片外像素。另用640x360视频确认不能误当仪表画面，做1、4、8线程并发独立会话。
