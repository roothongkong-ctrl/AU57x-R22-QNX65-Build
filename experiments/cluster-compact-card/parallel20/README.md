# R7 / 一张高德原卡片，20项云端测试

基线：MacsInSpace/mib-cluster-map v1.2.14。最终画面只需要一张高德原生白色转向卡片缩小至70%，完整地图显示不缩放，中控屏不改。

本次只新增GitHub Actions工作流，不修改原版MIB文件。20个独立任务由 5项功能 × 4种编译配置组成（GCC调试、GCC优化、GCC+ASan/UBSan、Clang优化）。

五项覆盖：
1. 原卡片像素缩放、背景不变与450例边界测试
2. 中控110和仪表111的隔离，2万项模拟事件
3. 复用官方v1.2.14视频解析器的卡片socket接收，1000次重连及异常
4. 112握手实验、独立端口与300次断开重连
5. v1.2.14播放器3行补丁准确应用及Linux源码编译

max-parallel=20只是运行上限，实际并行数取决于GitHub额度和运行器资源。

局限：20个测试全通过也不能证明iPhone/高德提供112号独立视频流、真实AES密钥、QNX ARM编译或车机运行。该工作流不产出车机安装包，不能装车。正式程序仍需要经实证确认的独立卡片视频和卡片透明背景处理。
