# R24–R26 并行整合（研发版，不可直接装车）

基线：MHI2_CN_AU57x_K1006_2 / MU1005，800×298，MacsInSpace/mib-cluster-map v1.2.14。
仅在独立实验分支构建，不改原车、不改主分支。

## R24 播放器
- 复用原有 111 H264 → I420 → frame pool → GLES 链路。
- 软件解码、NvMedia 解码到内存均在 frame pool 发布前使用同一实验合成器。
- NvSS 直接显示没有 I420 缓冲；停用合成器，原画面保持不变。
- 默认编译无实验代码；实验编译仍要求显式环境变量、原 19820 CarPlay 路径、800×298。
- 112 及 ROI 是测试假设，不是正式高德已证实协议。不得自动启用。

## R25 ARM
使用上游公开 QNX65 ARMv7 8.5 工具链、FFmpeg 6.1.5、原 NEON 对齐审计，分别构建默认与实验播放器。云端生成 ELF 和 SHA256 检查报告。Linux 语法检查不等于 QNX 硬件运行验证。

## R26 安装及恢复
优先复用上游 SD 软件更新、备份、卸载、原设置保留逻辑，不修改其原厂系统文件处理脚本。
先运行上游 simtest，验证原脚本的安装、卸载、恢复流程。
最终包必须通过以下条件后才制作可安装版：
1. 高德独立层或其它无损卡片处理方案已验证；实际 ROI 与帧尺寸明确。
2. QNX ARM 实验二进制完成编译，依赖及 NEON 审计通过。
3. 以原版完整 v1.2.14 SD 包为基础，替换受控播放器，重新生成校验和与更新元数据；保留原版及恢复材料。
4. 默认关闭实验功能；没有验证条件时原地图不变。
5. 车机更新前须备份、禁止行驶时安装或测试；有恢复方案后才可进行静止车辆测试。

本阶段只发布研究文件、编译证据及原 SD 测试日志；不发布自动执行的 SD 包，不宣称实车兼容。后续完整包使用上游打包器生成，避免手工修改已校验的更新元数据。
