# R39：从 MU1005 回调快照到 RFCOMM 排队的离线接线

源码 `cp_mu1005_bridge.[ch]` 把 R38 的16字节原厂事件**纯解析候选**连接到 R24 规范化 `AuRfIngress` 收发队列。只在外部得到已认证原厂callback owner证据时才调用；事件1记录待审批的配对设备（**不自动 accept**），实际原厂确认后事件2建立当前代际，事件5拷贝入队，事件6必须额外校验异步TX token；事件4断开并禁止旧实例复用。

GitHub host 测试包括不同epoch拒绝、配对请求与独立授权、连接、数据、异步发送完成、有线/旧连接隔离；QNX 22个模块编译+QEMU加载符号测试。

**绝非原厂 hook 或真实无线 iAP2/MFi**。缺实际 BlueSDK 合法回调分配/线程锁、原车端点与AirPlay会话。在未取得真实OEM owner证据前不会提供安装载荷。
