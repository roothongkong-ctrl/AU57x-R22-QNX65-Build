# R38：MU1005 蓝牙回调16字节快照解析器（只读研发）

旧 R14 原厂样本提供的事件类型 1/2/4/5/6、16字节布局、16位长度和32位指针信息，在当前源码实现了**不访问任何固定OEM地址**的独立解析器 `cp_mu1005_callback.[ch]`。必须由外部真实 owner 提供：序列化线程验证、合法配对身份、按本次调用有效的原厂内存快照读取。数据先复制进 caller-owned buffer，绝不对事件内指针直接解引用。

负向用例拒绝越界长度、过期会话、无owner、未经配对、失效读内存、异常事件，并进行20,000个确定性垃圾回调快照的 ASan/UBSan 测试。解析器被纳入 QNX 第21个C模块，客体QEMU只检查可加载符号。

**未打通的关键边：** 本固件真实 BlueSDK callback 注册、入口地址/ABI时序、原厂 mm-ipod/iAP2 的物理流通道与合法MFi。不能借此推断无线CarPlay可运行，也不是固件补丁或可安装DLL。
