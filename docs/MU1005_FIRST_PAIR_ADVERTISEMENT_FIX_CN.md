# First-time Bluetooth pairing lifecycle corrected
The earlier R113 called paired_phone() before RF/SDP publication, making first-time discovery impossible. This update separates OEM SDK publication (image/thread/MFi hardware/wired idle) from peer authorization (paired phone + R105) and keeps R105 gate EMPTY until an independently authenticated peer exists. When USB wins before pairing, advertisement is retired only on the original owner under a quiescence witness. Native inbound_event still independently requires the OEM peer-auth callback to allow an incoming link. This is not a handset connection or proof of production BlueSDK binding. NO_INSTALL.
