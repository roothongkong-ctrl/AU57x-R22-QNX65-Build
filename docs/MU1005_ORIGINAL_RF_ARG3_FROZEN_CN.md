# MU1005 original RFCOMM registration argument: no unproved donor zero
The previous original adapter called native inbound_register_rf() with its legacy donor argument 0. R101 original-owner evidence review instead required an independently attested 1..30 input and explicitly labelled the zero option experimental. This change adds inbound_register_rf_original() with a nonzero OEM-attested input. mu1005_native_gate_make() now requires rf_arg3_proven callback on the original image/thread and freezes its 1..30 returned value BEFORE any SDK registration side effects. The SDK-allocated output SCN is separately checked and written to SDP; input and output may differ. Legacy donor inbound_publish() remains unchanged for compatibility, but is NOT the pinned MU1005 production route. Missing OEM witness means registration is blocked (no guessing), and no actual OEM provider is bundled. Unit-test callbacks are synthetic, NOT real OEM proof. DO_NOT_INSTALL.
