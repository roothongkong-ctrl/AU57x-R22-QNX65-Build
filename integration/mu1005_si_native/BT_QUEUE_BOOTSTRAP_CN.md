# 从启动方进入原厂事件线程（NO INSTALL）
实际 original btstack：0x11ec98 写 this+0x1b0=1，0x11ec9c add sp,#284，0x11eca0 pop r4-r11,pc；上游 LuKa 参考的 0x11ec60 位于 started 标志之前，不能直接作为新的启动完成判据。历史 libutil 原始 ELF PT_DYNAMIC 动态符号确认 SharedPtrDefaultBase ctor (void*,void(*)(void*,void*),void*) 0x6f5f4，copy 0x6e3f0，析构 0x6fc5c；析构实际 0x6f608 中 0x6f64c 读 control.context，0x6f650 读 object，0x6f654 读 deleter，0x6f658 BLX，参数顺序与周期事件自定义 deleter 一致。libcomm stop 0x4e114、enque 0x4e620、threadLoop 0x4e9bc、dispatchEvent 0x4d828 来自动态符号，不假定 stop 排斥已证明。
新增 mu_bt_osapi_target：读取真实队列 thread id，而非要求启动 caller 已在 AO；原有严格 owner check 仍禁止 tid=0。新增 mu_bt_queue_bootstrap：在真实 startup 授权及 lifecycle lease 下取得 AO 引用，首次独立事件实际处于 AO 时检查其身份并调用 queue-only bind，之后调用现有 wireless drive。不修改 stock notify 或 timer。不是自动加载：需要真实 startup 调用者、真实 lease/mapping/provider、回调锁安全与恢复证明。host 测试新增 target ID、错误 caller、无效 tid 和对象变化；ARM 编译待确认。QNX run 45562229449 的 worker/owner 两次 TCP 生命周期步骤已成功，SDK/原厂 callback 是 fixture；不可称真机无线 CarPlay 成功。
