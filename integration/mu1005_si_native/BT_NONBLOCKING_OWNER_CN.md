# MU1005 native owner nonblocking socket handoff (NO INSTALL)
The exact original btstack imports comm::ActiveObject::enque at PLT 0x117900 and osal::MutexOps::init at 0x11787c. DT_NEEDED contains libcomm.so and libosal.so. The actual event-loop implementation and mutex option semantics are external to btstack. Need original matching files before establishing safe owner binding; do not assume reentrant mutex semantics.
au98_adopt / au98_adopt_stock_native accept an exclusive prepared nonblocking loopback descriptor, validate endpoint and live status, and require independent daemon identity verification for that fd before attaching. No connection wait on SDK dispatch. Preflight failure leaves descriptor with caller; successful or uncertain attachment transfers ownership. Existing legacy connect path remains for compatibility, not for use in SDK callbacks. Production daemon identity witness and owner dispatch provider remain unimplemented. MFi unchanged.
Host regressions added: blocking descriptor rejection, denied/revoked identity, wrong port/thread, success and withdrawal. These are host fixtures, not actual OEM thread proof. ARM exports added to CI. No installation package or production hook.
