## 新增接口
- `txn_supervised_trial`: 在同一维护锁内执行原版状态检查、停止服务、试装、启动候选、候选健康确认、提交。启动/验收失败时，先经 quiesce 确认停止，再恢复并请求启动原版。停止无法确认时不覆盖文件。
- `txn_supervised_recover`: 独立恢复入口，在锁内识别未提交事务、验证停止、恢复并请求启动原版；尚无 journal 时仅在全部原厂文件匹配时允许重新启动原版；已提交版本仅核验文件，不误回滚。若 journal 无效或文件未知则拒绝覆盖。
- 生命周期结果 0 = 提交成功（recover 中为已提交文件检查成功），1 = 原厂文件已恢复/确认未变且原版启动回调成功，-1 = 阻塞，需要人工/独立恢复。回调必须有界、独立验证并且不能再次进入 txn 锁。确认时目录同步失败导致 journal 结果不明则阻塞，不盲目覆盖候选。
- `supervisor_fixture.c/h` 为专用 Linux 主机测试替身，使用 fork/pipe/poll/waitpid 测试候选子进程启动、健康应答、超时、退出与跨进程锁冲突；原版启动回调只是测试记录，不代表真实原版服务启动。没有车机路径、MIB 启动脚本、生产健康探针或自动开机触发器。
