# R105.280 原厂蓝牙运行模块整合（NO INSTALL）
复用既有原厂 BlueSDK 接入、原厂启动观察、同 ACL 自动恢复、继承 FD 的实际 Rust daemon。合成一个 QNX 6.5 ARM DSO，严格禁止未解析链接符号，并验证所有关键入口，原有 donor ELF 保持独立进程。不同 OEM 进程的 SI/DIO 模块仍独立，不能直接加载到 btstack。原厂 LD_PRELOAD 构造器默认不启动无线，仍缺少经证明的生命周期互斥、AO owner、wired-idle 等实际调用方及受控部署。只验证静态链接及制品来源，非实车连接；禁止安装。不得绕过原厂 MFi。下一步必须提供实际调用方而非再次复制库。
